# Design law review: 29 October 2026

Review scope: public movement study, shared primitives and shell, auth, movement
library, recovery, dashboard and inherited application screens. The law supplied
in the conversation was re-read, including its later refinements. Where its earlier
examples conflict with later prohibitions (grids, entrance reveals, accent colors,
underline animation), the later specific restriction wins.

Verification: rendered desktop and 390/375px mobile screens; real pointer and
keyboard tests; reduced-motion and JavaScript-disabled public renders; authenticated
database flows; camera lifecycle tests. The illustration is explicitly synthetic,
uses the app's angle calculation, and is never presented as measured form evidence.

## Signature formula and field notes

- Artifact: interactive synthetic movement study with actual joint geometry.
- Atmosphere: a mineral print surface and forest ink, rather than a generic tech glow.
- Depth: overlapping reference positions, articulated foreground and substrate.
- Product specificity: camera framing, local processing, real supported catalog and session evidence.
- Display character: self-hosted Sporting Grotesque, quiet system body.
- Silhouette: custom three-position mark and moving figure.
- Navigation: integrated public masthead and considered application sidebar/mobile sheet.
- Real claims: starter dance course only; no invented workout counts, customers or model accuracy.
- Cohesion: one related palette and one type voice throughout shared surfaces.
- Creativity: an authored movement diagram, not a stock realistic photograph.
- Reference language: no reference copy, dashboard prop or borrowed brand content.
- Free font concerns: no repeated Google default pairing or external font request.
- Motion: responds to user input, supports reduced motion, never hides content to reveal later.

Residual product validation is separate: real-service Clerk/Redis staging and physical
camera/device evidence are still release requirements. This UI review does not establish
biomechanical validity, full accessibility certification or a live deployment.
